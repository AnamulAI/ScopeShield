# Demo video: shot list

A shot list only. The narration script is written separately. Every shot below uses the live site, https://scopeshield.anamulhoque.com (fallback https://scopeshield-1la.pages.dev), in Demo mode, so the recording spends no credits. Deep links open a recorded sample directly: `/#sample=bakery`, `/#sample=fitness-app`, `/#sample=brand-studio`; add `&open=1` to start with the change orders expanded.

Recording setup: 1920x1080 browser window at 100% zoom, light mode, notifications off, cursor visible, one take per shot, no UI changes between takes.
